# HealthHub by MedSource Letterhead

| | |
| --- | --- |
| Date | Oct 13, 2026 |
| Type | Print, letterhead template (header and footer images) |
| Location | Brand level, HealthHub by MedSource |
| Status | Draft |
| Design | [MedSource HealthHub Design System](https://claude.ai/artifact/9rBBbMZtz8yim7BnH17PUR) (flat navy #033F75 and green #5FA122, Nunito). MedHealth logo carried over with the name changed to HealthHub by MedSource. Source: [source.html](source.html) |

Follows the HealthHub design system: flat colour only (gradients stay inside the logo), navy bars on the outer edges with a thin flat green accent line next to the white area, tagline "Advancing Healthcare Solutions" in Nunito SemiBold grey with a short green rule. The lockup keeps HealthHub and a smaller "by MedSource" on one baseline with the descriptor beneath, set to the full row width and tracked +6%. Gaps are measured from the wordmark cap height X (mark to text 0.45X, row to descriptor 0.55X), the descriptor aligns with the H stem and the end of MedSource, and the text block is centred on the cross. The standalone logo uses the design system ratio (mark about 2.05X). The tagline vertically centred on the wordmark cap height in all three pieces (header first page has no underline so it stays inside the optional tagline band). The cross and heartbeat mark is untouched (cropped from the supplied MedHealth logo). Only the name changed: "MedHealth" became "HealthHub" with a smaller "by MedSource", in the logo's own Poppins lettering, with the descriptor kept the same width as the wordmark.

Fitted to [LETTERHEAD-SPEC.md](../../../LETTERHEAD-SPEC.md). First page header keeps Zone A (branch tag) and Zone B (phone, email, address) blank because the system prints them. The logo ends at x 1184, y 340, nothing sits under the logo, and only the optional tagline sits at the top right.
