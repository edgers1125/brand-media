# MDS fonts

Fonts for the MDS scrub brand only. MedSource publications use Poppins (../poppins).

- `Jost-Variable.woff2`: Jost, weights 100 to 900. Every MDS text style. Fallback: Futura, Century Gothic.
- `CormorantGaramond-Italic-Variable.woff2`: Cormorant Garamond Italic, weights 300 to 700. The single `accent` word per layout only.

Both are open licence (SIL OFL) and free on Google Fonts, where TTF versions can be downloaded for Canva and Word.
