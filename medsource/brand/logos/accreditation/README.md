Accreditation logos for MedSource publications and signage. Kept separate from the MedSource logo files. Use them only next to a real accreditation (DSWD AICS Guarantee Letter, PhilHealth YAKAP Gamot) and never recolor or redraw them.

## DSWD

- `dswd-logo.svg`: DSWD logo, clean vector redraw of the reference file EJ supplied (Oct 2026), traced shape for shape. Use for print and signage.
- `dswd-logo.png`: the same logo at 2000 px wide, transparent outside the shield. Use for Canva, documents and quick social work.

Colours: yellow #FFD200, blue #0400B7, red #F70000, white inside the shield.

Current use: AICS card on panel 3 of the warehouse window sticker, as "AICS / DSWD GL / ACCREDITED" with the logo to the left.

## PhilHealth YAKAP (vectorized Oct 23, 2026)

Rebuilt from the small raster crops of EJ's banner (`posts/2026-10-23-accreditations/source/ph.png`, `yk.png`), which went soft when enlarged.

- `philhealth-wordmark.svg`: "PhilHealth" rebuilt from Poppins Bold outlines (the wordmark's typeface, 97% match), letter spacing -0.03 em.
- `yakap-wordmark.svg`: "YAKAP" is custom lettering (no font match), so it is a smoothed trace of the original, 98.5% match.
- `philhealth-yakap-stacked.svg`: PhilHealth over YAKAP, same width, at the proportions used on the Facebook cover and posts.
- `philhealth-yakap-gamot-accredited.svg`: stacked lockup plus the yellow "GAMOT ACCREDITED" pill. This is the badge used on the Facebook cover, the Oct 23 accreditations post and the window sticker.
- Each SVG has a matching PNG at 2000 px wide with a transparent background.

All text is converted to outlines, so no fonts are needed to open them. The stacked layout and the pill are MedSource's own arrangement, not an official PhilHealth layout.

Colours: PhilHealth blue #56A0D8, YAKAP yellow #FFB700, pill text navy #033F75.
