# MDS logos

MDS Medical Scrubs & Apparel, the scrub suit sub-brand of MedSource. Monotone (single colour) for a premium, minimalist feel. It does not follow the MedSource colours. Every logo comes as SVG (vector, send this to printers and embroiderers) and PNG (transparent background).

Colour: Slate #3D4A5C. Tagline line is part of the logo. Rules, colours and type: [guidelines/mds-brand-guide.md](../../guidelines/mds-brand-guide.md).

| File | Use |
| --- | --- |
| `mds-stacked-slate` | Primary logo, everyday use, print, web |
| `mds-stacked-white` | Primary, reversed. White on Slate or other dark grounds |
| `mds-horizontal-slate` | Horizontal layout, headers and wide spaces |
| `mds-horizontal-white` | Horizontal, reversed |
| `mds-chest-slate` | Chest mark for light fabrics, no tagline |
| `mds-chest-white` | Chest mark for dark fabrics, no tagline |
| `mds-icon` | Avatar, favicon, labels |
| `mds-icon-white` | Icon, reversed. Social sign-off on slate or photos |
| `mds-stacked-deep-teal` | Alternate (#2C5F63) for a seasonal or limited line |
| `mds-stacked-gold-foil` | Gold foil (#B8975A) on deep slate #2E3947, packaging and hang tags only |

The white versions have a transparent background, so they look empty on white. Source design: the "MDS Logo" canvas (Oct 3, 2026) in Claude.
